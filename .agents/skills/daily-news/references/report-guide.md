# 报告与来源记录

保留原每日早报的分析目标：追问为什么发生、可能如何发展，避免仅转发新闻。先核查再下结论，来源不足时如实说明。

对选中的新事件，分析背景、时间线、关键数据与不同说法。政策关注出台背景、影响链和受益/受损方；产业关注市场格局、资本和竞争；科技关注技术路线与产业化；社会事件关注结构性问题和历史可比案例。说明二阶影响以及未来1–3周值得跟踪的事项。

报告通常包含：

- 今日关键事件：每条2–3行，优先与昨日不同的新事件。
- 深度分析：逐条写背景与脉络、事实核查、底层逻辑、影响与前瞻。
- 跨事件关联：明确区分事实联系与分析推断。
- 值得警惕的信号：1–2个有依据的风险点。
- 参考来源：关键说法就近引用，列出查询过的原始URL、来源标题和已知的发布日期。

正文用简洁中文，区分已证实事实、推断和预测。不要把旧数据当成当天的新进展，也不要把两个转载同一稿件的网站视为两个独立来源。避免复制大段来源正文。

来源记录可保存为以下 JSON，供复查；字段按实际可取得的信息填写，缺失数据不编造：

```json
{
  "sources": [
    {
      "title": "来源标题",
      "url": "https://example.com/original-release",
      "published_at": "YYYY-MM-DD",
      "checked_at": "YYYY-MM-DD",
      "claim": "该来源支持的关键事实",
      "notes": "原始发布、与其他来源一致或存在冲突"
    }
  ],
  "limitations": ["尚无法独立核实的内容"]
}
```

每次修改正文时同步提供来源 JSON。正文发生变化但省略来源时，工具会清空旧来源，避免新报告沿用旧报告的核查资料；正文不变且未提供来源时保留已有记录。

工具只保存这些资料，不访问来源URL或判断事实是否正确。Agent 对来源核查、引用和结论负责。不把模型内部推理、密码或API密钥保存到来源记录。
